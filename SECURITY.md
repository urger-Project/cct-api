# Política de segurança

## Versões suportadas

Enquanto o projeto estiver na série `0.x`, correções serão aplicadas à branch `main`.

## Relato responsável

Não publique credenciais, dados pessoais ou detalhes exploráveis em uma issue pública.
Use o recurso privado **Report a vulnerability** do GitHub quando ele estiver habilitado.

Inclua uma descrição do impacto, passos mínimos para reprodução e uma sugestão de
mitigação, se disponível. Evite acessar ou modificar dados que não pertençam a você.

## Escopo sensível

Falhas que possam alterar instrumentos, confundir fontes oficiais, expor dados pessoais
ou permitir injeção de conteúdo recebem prioridade. Divergências jurídicas ou de
interpretação de cláusulas devem ser tratadas como problemas de dados/documentação,
não como vulnerabilidades de segurança.
